# Roblox games database

Purpose: reference for checking that game ideas are original and not saturated. Not a source of design advice by itself.

Files
- `games-2025.md`: games that went viral or held the charts in 2025.
- `games-2026.md`: 2026 breakouts (full entries) plus veterans carried over from 2025 (one-line status).
- `saturation.md`: crowded formats, clone counts, and what makes hits last vs fade.

Columns
- **Mech**: the core loop in one line.
- **Why viral**: the hook that spread it (meme, creator, mechanic, IP, event).
- **Span**: how long it trended and whether it lasted or faded, with the reason.
- **Sat**: clone saturation of its format. L = few clones, M = dozens, H = hundreds, VH = a naming template ("Steal a ___", "+1 Speed ___").
- **Src**: S = confirmed from 2026 sources (StudioKrew, RoWatcher, Max Power Gaming, Newzoo, Wikipedia, games.gg, Roblox Innovation Awards); K = from model knowledge up to mid-2026, verify before relying on it.

Peak and CCU figures are approximate snapshots from third-party trackers (GGAID, Rolimons, rblxdb) and vary by source.

Snapshot date: 2026-10-24.
