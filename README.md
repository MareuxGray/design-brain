# design-brain

Shared guidance and reference for making Roblox games. Game-specific details don't belong here, and this repo is public.

## How to use it

- Find the file below, then read only the section you need: `grep -n "^## " <file>`.
- Check the evidence grade before relying on a claim: **S** strong or official, **M** moderate, **P** practitioner, **A** our own analysis.
- Most research reports end with audit criteria. Use them to review a design.
- In `games\`, entries marked **K** come from AI model knowledge. Verify them before relying on them.
- Roblox policies and trends change quickly. Re-check official docs before launch. The games data is a snapshot from 24 October 2026.
